# NOVA Market ✦

فروشگاه نمایشی مینیمال و واقع‌گرایانه با هویت مستقل NOVA Market.

**شعار:** «کمتر بگرد. بهتر انتخاب کن.»

## امکانات
- صفحه اصلی و محصولات
- ۱۰ محصول با قیمت‌های نمونه به‌روز بازار دیجیتال ایران
- دسته‌بندی‌ها و فیلتر محصولات
- سبد خرید با ذخیره‌سازی localStorage
- ساخت حساب کاملاً نمایشی در localStorage
- ثبت سفارش نمایشی، آدرس، تاریخ و بازه تحویل
- صفحه تأیید سفارش با کد سفارش
- صفحه ارتباط با ما و فرم نمایشی
- لوگوی SVG اختصاصی داخل هدر
- طراحی RTL، واکنش‌گرا، Dark / Glass UI
- **بدون پرداخت واقعی و بدون ارسال اطلاعات به سرور**

## WordPress
تم اصلی در `wp-content/themes/nova-market` قرار دارد. پوشه را داخل `wp-content/themes/` وردپرس قرار دهید و از پنل Appearance > Themes فعال کنید.

## قیمت‌ها
قیمت‌های نمونه در تاریخ ۱۷ شهریور ۱۴۰۵ / ۸ سپتامبر ۲۰۲۶ از داده‌های بازار دیجیتال ایران الهام گرفته شده‌اند و برای دمو هستند؛ قیمت‌ها تضمین یا پیشنهاد خرید نیستند.
